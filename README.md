# Moon Quantile

A MoonBit-native, mergeable logarithmic quantile sketch for latency and size metrics.
Development began 2026-11-24. This is an AI-assisted original implementation of the
DDSketch mathematical approach, not a claim to have invented that algorithm.

Planned contract: signed values, explicit bounded storage, transactional merge,
weighted observations, deterministic snapshots, and reproducible error tests.
No network requests or external runtime dependencies in the library.

Competition registration, public release, and awards are not yet completed.
